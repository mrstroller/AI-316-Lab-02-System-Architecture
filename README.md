# AI-316 Lab 02 — System Architecture

## Course

**AI Project Design and Development (AI-316)**
Air University Islamabad
Faculty of Computing & AI

## Lab Objective

This lab focuses on analyzing system requirements and designing the architecture of an AI-based system using requirements engineering, system boundaries, data flow diagrams, and modular software design.

## System

**Smart Automated Attendance System**

The system is designed to use AI-based object detection and analytics to automate attendance-related processes.

## Tasks Completed

* Defined functional and non-functional requirements.
* Identified system boundaries, actors, inputs, outputs, and constraints.
* Designed Level 0 and Level 1 Data Flow Diagrams (DFDs).
* Identified major system components and their responsibilities.
* Designed a modular software architecture.
* Created Python class and method skeletons for major modules.
* Mapped requirements to system architecture components.
* Consolidated the architecture documentation into `ARCHITECTURE.md`.

## Main Modules

* `DataIngestion`
* `ImagePreprocessor`
* `ModelInferenceEngine`
* `AlertLogger`
